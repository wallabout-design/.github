# .github

Default community health files for repos in the `wallabout-design` org. GitHub uses `PULL_REQUEST_TEMPLATE.md` for any org repo that doesn't have its own.

Don't edit the template here first: the source is `templates/PULL_REQUEST_TEMPLATE.md` in `wallabout-design/standards` (private), with the rules in `standards/pull-requests.md`. Change it there, then copy it here.

This repo must stay public, or GitHub ignores it.
