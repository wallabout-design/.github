# .github

Default community health files for repos in the `wallabout-design` org. GitHub uses `PULL_REQUEST_TEMPLATE.md` and `ISSUE_TEMPLATE/issue.md` for any org repo that doesn't have its own.

Don't edit the templates here first: the sources are `templates/PULL_REQUEST_TEMPLATE.md` and `templates/ISSUE_TEMPLATE/issue.md` in `wallabout-design/standards` (private), with the rules in `standards/pull-requests.md` and `standards/issues.md`. Change it there, then copy it here.

This repo must stay public, or GitHub ignores it.
