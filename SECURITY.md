# Security policy

If you find a security problem in a wallabout design repository, please report it privately. Do not open a public issue, because that shows the problem to everyone before we can fix it.

## How to report

Use the **Report a vulnerability** button on the repository's **Security** tab. This sends the report to us privately on GitHub.

Include what you need us to understand it:

- the repository, page or endpoint affected;
- the steps to reproduce it;
- what you expect an attacker could do;
- any proof of concept, screenshot or log, with no personal data in it.

## What to expect

We aim to reply within five working days, to confirm the problem and say what we will do next. We will tell you when it is fixed, and we are glad to credit you if you would like that.
